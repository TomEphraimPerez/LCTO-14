# Let's Check This Out! 
# LCTO-14 is an app for the common good, and helps grocery shoppers 
# shop without getting cheated as far as product performance, taste,
# processed-foods package-images vs true-outcomes, cost,and more.   
# It's free to use. The shopper can post a comment regarding the pro-
# duct and give it 1 to 5 stars ratings. In addition, a user can soon
# take a photo of the product's picture, and compare it with what it
# actually looked like afterwards. 
# A user can search for a product as well, using at least one API. 
# More features will be announced.

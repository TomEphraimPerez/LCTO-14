# Let's Check This (product) Out! 
# LCTO-14 is an app for the common good, and helps grocery shoppers 
# shop without getting cheated as far as product_performance, value, looks, and taste.
# It's free to use. The shopper can search or post comments on products.
#
# It's especially good for use for shopping for processed_foods vs 
# true-outcomes (ie., what it looks like straight out of the oven or microwave).   
# Good for also comparing what the TV ad image looks like, vs what you REALLY get.
# These "Images" APIs are soon to be developed. 
#
# A user will soon take a picture of the product's TV image or package image, 
# and compare it to what you actually get. This is TBA.
#
# Give it 0 to 5 Stars as your rating. The top of the UI shows the average # Stars.
#
# A user will also soon be able to search for a product using images of the product
# or its barcode.
